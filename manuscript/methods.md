**Input data.** Tapestry takes PacBio HiFi reads aligned to GRCh38 together with a joint-called variant set spanning every member of the pedigree. For the analyses reported here for the CEPH K1463 pedigree, small variants were called per sample with [DeepVariant](https://github.com/google/deepvariant) — which emits per-sample gVCFs — and joint-genotyped across the pedigree with [GLnexus](https://github.com/dnanexus-rnd/GLnexus).

**Read-backed phasing.** Each sample is read-backed phased with [HiPhase](https://github.com/PacificBiosciences/HiPhase) v1.5.0 (`run-hiphase.sh`), yielding a phased VCF, a table of read-backed phase blocks, and a haplotagged BAM (`HP`/`PS` tags).

**Genetic phasing.** The IBD segments with founder labels (Fig 2E) and the deduced `paternal|maternal` genotypes (Fig 3D) are computed from a PED file and the unphased joint-called VCF by the Rust tools `gtg-ped-map` and `gtg-concordance`, respectively ([Platinum-Pedigree-Inheritance](https://github.com/Platinum-Pedigree-Consortium/Platinum-Pedigree-Inheritance); `build-iht-based-haplotype-map-and-phase-variants.sh`). `gtg-ped-map` retains only informative sites that pass quality control (high genotype quality, sufficient depth, and no missing genotypes across the pedigree, with defaults: variant quality ≥ 20, depth ≥ 10), enforces Mendelian transmission and excludes violating sites, then merges informative sites along each chromosome into haplotype runs and prunes runs supported by fewer than a minimum number of sites (default 10). `gtg-concordance` phases the remaining variants and quarantines any site that no founder-allele assignment can explain, thereby filtering residual sequencing errors and Mendelian violations.

**Methylation calling.** Per-CpG methylation is computed for each haplotagged BAM, stratified by `HP` tag, with [pb-CpG-tools](https://github.com/PacificBiosciences/pb-CpG-tools) v3.0.0 (`aligned_bam_to_cpg_scores.sh`; minimum coverage 10, minimum mapping quality 1) in both of its modes — *count-based* (fraction of reads methylated) and *model-based* (a neural network mapping read kinetics to methylation probability). Both modes are carried through to Tapestry's output.

**Rebucketing and all-CpG expansion.** The rebucketing of Fig 4B is implemented in `phase_meth_to_founder_haps.py` (`phase_meth_to_founder_haps.sh`), which combines the `hap1`/`hap2` methylation BEDs from the previous step with the read-backed and genetic phasings. `expand_to_all_cpgs.py` (`expand_to_all_cpgs.sh`) then extends the result to every CpG in the reference and sample genomes, adds unphased methylation where founder-phased values are absent, and uses heterozygous SNVs to flag *allele-specific* CpGs — those present on only one homolog.

**meQTL validation.** Tapestry's founder-phased methylation was evaluated at three published meQTLs (Fig 5) following the workflow in the [`experiments/benchmark-tapestry.1.ipynb`](https://github.com/quinlan-lab/tapestry-tools/blob/main/experiments/benchmark-tapestry.1.ipynb) notebook of the [tapestry-tools](https://github.com/quinlan-lab/tapestry-tools) repository. In that repository, `compute-methylation-loci` averaged per-homolog founder-phased methylation over the interval around each meQTL; `prepare_meqtl_coords.sh` looked up each meQTL's GRCh38 position and alleles from the Ensembl REST API and read the per-sample paternal and maternal allele at each meQTL from the joint-called VCF; and `correlate_methylation_with_haplotypes` related each homolog's methylation to its founder label and to the meQTL allele it carries.
